# Usland 音频素材包

本包包含实际可播放的37个MP3文件：6首背景音乐、8个环境声、23个操作/事件音。不是链接清单。

## 快速使用
1. 解压整个文件夹，双击 preview.html 试听；如本地浏览器有限制，可在本目录运行 `python -m http.server 8000` 后访问 http://localhost:8000/preview.html 。
2. 将 static/audio 整个目录复制到 Flask 项目的 static/audio。
3. 按 audio_manifest.json 中 path、trigger、recommended_volume 和 loop 配置接入。路径以项目根目录为基准。
4. 在设置页面添加音频致谢链接 `/static/audio/credits.html`，保留 credits.md 与 licenses。三首背景音乐采用 CC BY 3.0，需要对用户展示署名。其他素材为来源页标注的 CC0。

## 目录
- static/audio/bgm：6首完整音乐。
- static/audio/ambience：4个循环环境声和4个偶发/条件环境音。
- static/audio/sfx：23个操作和事件音。
- static/audio/credits.html：可直接在应用中链接的署名页面。
- preview.html：37项分类试听。
- sound_list.csv：中文清单，Excel可打开。
- audio_manifest.json：逐项触发、音量、源文件、授权、加工记录与时长。
- credits.md、licenses：署名、许可及来源页授权摘录。
- event_map.md：其余业务操作的复用/静音规则。
- qa_report.json：实际文件解码与完整性检查。

## 选择与加工说明
这些是从 OpenGameArt 与 Kenney 发布页选取的现有作品，并经转码、适度均衡、峰值/响度控制及剪辑适配。6首音乐并非同一主题的定制变奏，实际长度约45秒至5分半，以文件清单为准。Forest Ambience 是带音乐性质的环境作品，与独立的自然树林录音 amb_forest 不同。

文件命名对应此前37项清单。信箱开盖、船体轻响、宠物抚摸/脚步是从锁扣、木盒、木质吱呀、布料或通用脚步录音适配的声音，不宣称是同名物体的现场实录。amb_cottage 是低通处理后的海浪，表现隔窗远海，不是独立室内录音。具体加工见清单。未加入合成AI生成音频。

## 播放与循环
- 所有音频都需由用户操作后启动，提供背景音乐/环境音/音效三类开关、音量和总静音。
- recommended_volume 是初始建议，仍需在实际页面用手机和电脑试听调整。
- 同时只播一首BGM。首尾经过淡化；音乐建议2秒交叉淡化，不保证节拍级无缝。自然环境已做交叉拼接，仍建议约1秒交叉淡化消除播放器接缝。
- 偶发风声/鸟鸣/船响不持续循环；壁炉仅在有对应画面时启用。
- 一次操作只突出一个事件音；不要把通用点击、成功提示和庆祝声叠加。
- 收到消息、和好邀请、任务状态按事件ID去重；初始历史加载、刷新、轮询和恢复标签页不补播。
- 标签页后台时暂停音乐与环境声。关闭声音立即生效。
- 音频失败不能阻塞聊天、保存和其他业务。

## 质量检查范围
逐项验证MP3可完整解码、文件时长、峰值与非静音。检查结果在qa_report.json。自动检查不等同于专业监听母带与全部设备上的听感验收，请用试听页完成团队最后的主观选择。
