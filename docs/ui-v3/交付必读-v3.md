# Usland 第三版交付说明（优先于旧版README）

直接双击 integration/demo.html 可以预览。五个入口可打开对应场景，支持Tab、Enter、Esc；这只是素材接入演示，不包含真实业务。

主岛双圆圈已改为共享野餐毯，角色脚底位置重新校准。背景完全不含动物和雕像；两者独立叠加。杯子、手账、水果已在背景中，不要重复叠加。

## 开发接入

1. assets整体复制到Flask的static/usland/assets，生产页面用url_for生成资源URL。
2. integration/scene_anchors.json为定位依据，scene-config.js是同数据可直接打开的版本。<=700px使用1440×2560竖图，其余使用2560×1440横图；场景容器保持原比例，不用cover裁切。
3. x/y为脚底落点。1024结果立绘显示宽度=1024×scale；left=x/背景宽，top=y/背景高；transform:translate(-50%,-94.043%)。1536素材按同一目标显示宽度换算，不直接套scale。
4. 16种动物由各自测试结果映射；未完成使用中性占位。首次进入由业务层引导到forest。两人状态独立，一方完成不改变另一方。
5. 雕像/侧身/和好姿态由另一组员交付，规范见character_asset_contract.json。文件未到时保持空雕像台，地图用结果立绘。阴影在雕像下面。不要请求缺失图片造成破图。
6. 入口键：forest测试、quest约会、cottage回忆、pier传话、mailbox设置。小信箱不是收件箱。demo触发usland:navigate事件；将打开素材预览替换成原项目业务导航。
7. 五功能背景位于assets/scenes/{forest,whisper,quest,memory,mailbox}。文本、照片、消息和表单使用HTML，正文放不透明浅色面板。业务权限、双人同步、隐私与API沿用原项目。

## 已交付范围

横竖主岛、五场景横竖背景、16张透明结果立绘、透明柔光与接触阴影、统一SVG图标和占位、视觉变量、定位配置、可点击预览、合成参考及资源清单。

背景是3D质感位图，不是可旋转模型。建筑与道具已烘焙；柔光图不是建筑切图，不能用于真实开门、开盖、摇船。此类造型动画需要额外分层素材。

结果立绘当前作为地图预览替身，不是最终侧身姿态。和好动画及雕像不计入本包完成项。两个animated WebP仅为可选亮度/光点原型，默认不使用；没有真正海浪/烟雾MP4。没有生成可编辑Figma文件。

压缩包不含历史源图和重复默认动物。检查文件完整性、尺寸、透明通道、定位、浏览器响应式及导航不等于真实Flask业务通过验收。查看qa_report.json和integration/browser_qa.json了解具体覆盖。

本次使用内置imagegen修改两张背景，无需用户API key。提示词：保留岛屿、视角、建筑、树林、海面和光照，仅将中央两个圆形站位改成一张奶油/陶土格纹野餐毯；后半部留给独立角色，前沿放两只杯子、共同手账和水果；不生成动物、文字或新建筑。横竖分别生成并缩放为统一交付尺寸。
